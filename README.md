# Descrição do Desafio

Neste projeto foi replicado duas páginas já criadas durante o curso com a sample disponibilizada, além de criar uma terceira página composta por: 

- Visual mapa 1: Soma de sales e unidades vendidas por país 

- Visual mapa 2: Soma de lucro (profit) por país 

- Visual de pizza: Lucro por segmento

## Objetivo do Desafio
Esse desafio visa treinar a habilidade de criação de visuais.
